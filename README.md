# 智慧教室管理平台前端

智慧教室统一管理平台的 Web 前端。单页应用，按服务划分功能区，目前「身份与访问管理」（IAM）、「录播调度」（smartclass-dispatchub，含 smartclass-webcam-server 设备管理）与「文件服务」（nsc-filehouse）三个控制台已实现，其余服务预留入口。

启动方法、部署指南等技术内容见[相关文档](#相关文档)。

## 功能范围

- 认证：密码 / TOTP / Passkey / OIDC 登录，注册、找回密码、邮箱验证、邀请注册
- 管理控制台：用户、团队、用户组、角色、权限、绑定、MFA 与密码策略、审计日志、邀请、假冒、签名密钥
- 录播调度（`/hub`）：学期与节次、教室与设备绑定、实时状态与手动录制/切换机位/抓拍、课表 CSV 导入、录播场次与产物下载、服务健康探针；设备页（`/hub/devices`）管理 smartclass-webcam-server 设备：注册与令牌轮换、在线状态与摄像头能力、录制场次与分段下载、照片预览与下载（按 `cam:*` 授权显示）
- 文件服务（`/file`）：桶管理与配额、对象浏览/上传（分片）/下载/删除、按 key 前缀过滤、预签名链接签发、我的用量、平台统计与配额覆盖、垃圾回收
- 个人中心：资料、安全设置、登录会话、登录活动、数据导出、账号注销
- 通用：浅色 / 深色 / 跟随系统主题；按登录账号的权限动态显示可见功能

# 智慧教室管理平台

智慧教室的统一管理入口。平台按服务划分功能，目前已上线「身份与访问管理」，其余服务将陆续开放。

## 功能一览

**身份与访问管理**

- 账号登录：支持密码、动态口令（TOTP）、通行密钥（Passkey）与单点登录（OIDC）
- 用户管理：新建与编辑用户、批量启停、CSV 批量导入、待审核账号审批、密码与服务凭据管理、登录会话查看与吊销
- 组织管理：团队与用户组的创建维护、组成员管理
- 权限体系：角色定义与权限分配、按用户/组/团队的权限绑定、MFA 与密码强度策略
- 安全审计：全量操作日志查询与导出、限时管理员假冒、签名密钥轮换
- 个人中心：资料维护、修改密码、两步验证、通行密钥、登录设备与活动记录

**通用体验**

- 浅色 / 深色 / 跟随系统三种外观模式
- 按账号权限自动展示可见功能，无权限的页面不显示

## 使用前提

平台需要连接身份认证服务（teamusers）才能工作，请确认该服务已启动且可被访问。

## 快速开始

```sh
pnpm install
pnpm dev
```

启动后访问终端提示的地址（默认 http://localhost:5173），使用管理员账号登录。

生产构建：

```sh
pnpm build
```

构建产物在 `dist/` 目录，交给任意静态文件服务器托管即可。如认证服务不在本机，启动前通过 `IAM_ORIGIN` 环境变量指定其地址。
